# API Contracts

Document request and response contracts here when an Edge Function becomes part of the public app flow.

Recommended file naming:

- `auth-login.md`
- `forum-create-post.md`
- `planner-generate-trip.md`
- `payments-redeem-voucher.md`

For each contract, capture:

- purpose
- caller
- auth requirement
- request payload
- response payload
- error cases
